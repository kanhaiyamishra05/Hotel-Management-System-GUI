# 🏨 Hotel Management System GUI

A modern and feature-rich **Hotel Management System Desktop Application** built using **Java Swing**. This application streamlines hotel operations with an intuitive graphical interface for room booking, food ordering, customer checkout, and real-time room availability tracking.

---

## ✨ Features

* 🛏️ Room Booking and Reservation
* 🍽️ Food Ordering Management
* 💳 Automated Billing and Checkout
* 📊 Live Room Availability Tracking
* 👤 Customer Information Management
* 🎨 Modern and User-Friendly Interface

---

## 🖥️ Technology Stack

* **Language:** Java
* **GUI Framework:** Swing
* **IDE:** IntelliJ IDEA / Eclipse / NetBeans
* **Architecture:** Event-Driven Desktop Application

## 🚀 How to Run

1. Clone the repository:

```bash
git clone https://github.com/kanhaiyamishra05/Hotel-Management-System-GUI.git
```

2. Open the project in your preferred Java IDE.

3. Compile and run:

```bash
javac HotelManagementGUI.java
java HotelManagementGUI
```
